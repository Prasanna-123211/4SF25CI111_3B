# Pandas Practice Exercises

This repository contains 13 Python Pandas exercises with solutions using Jupyter Notebook.

## Topics Covered
- DataFrame Creation and Operations
- Handling Missing Values
- Data Aggregation and GroupBy
- Merging DataFrames
- MultiIndex DataFrames
- Applying Functions and Lambda
- Text Data Operations

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## How to Run
1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install pandas numpy
   ```
3. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
4. Run all cells.

## Purpose
Created for practicing and understanding basic Pandas concepts through practical examples.
