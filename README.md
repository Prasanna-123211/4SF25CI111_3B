# 4SF25CI111_3B

## Milestone 1 – CIE
### Data Transformation, Null Value Handling, Insight Generation, and Visualization

This project analyzes the Netflix Movies and TV Shows dataset using Python and Pandas. It covers data cleaning, transformation, missing value handling, insight generation, and visualization.

## Tasks Performed

- Dataset Selection and Reading
- Data Understanding
- Data Transformation
- Null Value Identification and Mean Imputation
- Insight Generation
- Data Visualization using Matplotlib
- Final Observations and Conclusion

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

Netflix Movies and TV Shows dataset.

Source: [Kaggle – Netflix Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## How to Run

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib
   ```

3. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
4. Run all cells.

**Note:** An internet connection is required to load the dataset.

## Purpose

This milestone aims to develop practical skills in data analysis, data preprocessing, handling missing values, generating insights, and visualizing data using Python.
